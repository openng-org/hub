# Open Graph assets

Used by `scripts/postbuild.mjs` to draw the 1200×630 link-preview images (`dist/web/browser/og/`).

- `Jersey10-Regular.ttf` — Jersey 10 by Sarah Cadigan-Fried, SIL Open Font License 1.1
  (https://github.com/google/fonts/tree/main/ofl/jersey10). TTF here: resvg does not read woff2.
- `Inter.ttf` — Inter by Rasmus Andersson, SIL Open Font License 1.1
  (https://github.com/google/fonts/tree/main/ofl/inter).
- `logo.png` — the Angular Hub logo (public/images/logo.webp as PNG, which resvg embeds).
